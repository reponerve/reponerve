# RepoNerve v1.5.2

Release Date: 2026-10-09

Status: **Released**

---

# Summary

Patch release: **Correctness fixes and performance optimizations**.

* **Impact Traversal Fix**: `impact` now traverses inbound relationships (callers, importers, and implementers) to correctly answer "what breaks if I change X".
* **Human-Readable Contributor Display**: `ask` renders human contributor names and emails rather than hash IDs.
* **CLI Usability**: Silences Cobra usage dump on runtime errors.
* **MCP Protocol**: Dynamic semver in MCP server `initialize` handshake.
* **Workspace Setup**: `reponerve init` automatically outputs `.reponerve/.gitignore` containing `*`.
* **Scanner Performance**:
  * Skips `testdata/`, `fixtures/`, `dist/`, and build artifacts during file indexing walk.
  * Caches Tree-sitter grammars per language behind an `RWMutex`.
  * Asynchronous, non-blocking post-commit git hook.
  * Streaming record-delimited `git log` parser keeping memory flat on large repositories.
