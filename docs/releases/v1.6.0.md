# Summary

Minor release: **Repository Intelligence, Code Intelligence, and Developer Experience upgrades**.

---

# Highlights

## Ownership & Governance
* **Touched File Churn**: Extracts per-commit file paths and churn metrics (`--numstat`) into source metadata.
* **Recency-Weighted Ownership**: Computes dynamic directory and component ownership with recency decay half-life ($2^{-\Delta t / 180\text{ days}}$).
* **Bot Filtering & CODEOWNERS**: Excludes automated bot accounts and ingests GitHub/GitLab `CODEOWNERS` patterns into reviewer recommendations.

## Code Intelligence & AST Parsing
* **Two-Pass Call Resolver**: Resolves cross-package method calls, struct fields, and receiver types.
* **Express & Modern JS/TS Syntaxes**: Parses arrow function endpoints, member expression assignments (`exports.foo = ...`), and CommonJS `require()` dependencies.

## Agent Experience & Search Relevance
* **Repository Overview Intent**: Answers "What does this repo do?" from README and vision documentation rather than code structs.
* **Confidence Thresholds**: Word-boundary relevance ranking; returns clean "no match found" errors below confidence threshold; prioritizes primary architectural decisions.
* **Realistic Agent Guidance**: Instructs assistants to ground understanding with RepoNerve context first, then verify targeted source files.

## Storage & MCP Optimizations
* **Consolidated MCP `explain`**: Parameterized `explain` with optional target kinds (`file`, `function`, `struct`, `interface`, `type`).
* **Incremental FTS5 Updates**: Direct `IndexDocument` and `DeleteDocument` operations on `remember` and `forget`.
* **Schema Migration v10**: Cleanly drops legacy empty schema tables with rollback verification.

## Packaging & CI
* **Secure Installer**: `VERIFY=1` by default with macOS `shasum` fallback.
* **npm Checksum Validation**: Validates SHA256 release checksums during package installation.
* **CI Matrix**: Multi-OS test matrix across Ubuntu, macOS, and Windows with `gofmt -l`, `go vet`, and race detection.
